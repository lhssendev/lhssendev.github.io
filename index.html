02 / Featured work

Cloud Attack Surface Detector.

A hybrid scanner designed to connect public reconnaissance with cloud ownership context and structured audit output.

PythonBashAWS / Azure / GCPRecon

Map the exposed surface. Keep the cloud context.

Dynamic cloud environments create public resources quickly. This project helps classify exposed infrastructure and connect discovered services to known provider address boundaries.

  • Accepts individual targets, address lists, and CIDR ranges.
  • Maps IPs against provider-published AWS, Azure, and GCP ranges.
  • Performs service reconnaissance and banner collection.
  • Produces structured findings for security review and reporting.
